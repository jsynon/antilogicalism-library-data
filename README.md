# Antilogicalism Library Search Data

Search index data for the [Antilogicalism Digital Library](https://jsynon.github.io/antilogicalism/digital-library/).

## Current Dataset

**Version 47 (v47)**

- **644 books**
- **280,699 indexed PDF pages**
- Full-text search across a collection of philosophical, literary, historical, religious, and other classic works.
- Compressed search data loaded on demand by the browser.

## About This Repository

This repository hosts the searchable text indexes and metadata used by the Antilogicalism Digital Library.

The search interface is part of the main Antilogicalism website, while the indexed data is hosted separately through GitHub Pages.

The original PDF documents remain on Google Drive. Search results allow readers to locate relevant passages and open the corresponding source documents.

## Data Organization

The current production dataset is stored in:

`data-v47/`

Each dataset version is preserved independently to support testing, verification, and reliable updates.

New versions should be published in separate versioned directories rather than overwriting an existing production dataset.
